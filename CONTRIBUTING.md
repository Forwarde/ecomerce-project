# Правила работы с репозиторием

## Именование веток
* `feature/issue-<номер>-<краткое-название>` — для новых функций (например: `feature/issue-1-login-form`)
* `bugfix/issue-<номер>-<краткое-название>` — для исправления багов (например: `bugfix/issue-4-cart-total-fix`)

## Коммиты
* Сообщение коммита должно содержать номер issue: `#<номер> <описание>` (например: `#1 Add login template`)
