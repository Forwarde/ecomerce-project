# ЛЗ 13. Собственный ИИ-ассистент PM: автоматизация, верификация и экономия времени

## 1. Архитектура автоматизации PM-процесса

* **Автоматизированный процесс:** Еженедельный сбор статус-отчета проекта **AtelierFlow** и автоматическое выявление «зависших» рисковых задач (`Work Item Age ≥ 7 дней`) и открытых Pull Requests.
* **Реализация на 100% бесплатном стеке:**
  1. Python-скрипт [`scripts/pm_ai_assistant.py`](../scripts/pm_ai_assistant.py) — обращается к GitHub REST API (`Forwarde/ecomerce-project`), автоматически вырезает ПДн (`redact_pii`) и вызывает локальную модель **Ollama (`qwen2.5:7b`)** (с автоматическим fallback-отчетом в CI без GPU).
  2. Пайплайн [`.github/workflows/pm-assistant.yml`](../.github/workflows/pm-assistant.yml) — запускается автоматически **каждый понедельник в 09:00 UTC (`cron: '0 9 * * 1'`)** и вручную (`workflow_dispatch`), публикует отчет в `GITHUB_STEP_SUMMARY` и сохраняет артефакт `pm-weekly-status-report`.

## 5. Шаблон промпта и правила безопасности данных для команды

### 5.1. Утвержденный шаблон промпта команды
```text
Роль: Ты — ассистент ИТ-менеджера проекта AtelierFlow.
Контекст: Данные выгружены автоматически из GitHub REST API (JSON ниже).
Задача: Составь краткий статус-отчет на русском языке из 4 блоков:
  1) Выполненные коммиты; 2) Зависшие задачи (age >= 7 дней); 3) Открытые PR; 4) 2 рекомендации.
Ограничения:
  - Опирайся СТРОГО на переданный JSON. Не додумывай проценты, даты и стек.
  - Если данных недостаточно для вывода — пиши «Требует уточнения PM».
Формат вывода: Markdown-списки, объем не более 250 слов.
```

### 5.2. Инструкция для команды: какие данные ЗАПРЕЩЕНО передавать в ИИ
1. **Персональные данные клиентов и сотрудников (Закон РК о ПДн):** реальные ФИО, номера телефонов (`+7...`), ИИН, адреса доставки, реальные email-адреса. *(Перед вызовом модели скрипт обязан прогонять текст через функцию `redact_pii()`).*
2. **Секреты и учетные данные:** токены GitHub (`ghp_...`), ключи API, содержимое файлов `.env`, пароли от админ-панели и БД.
3. **Коммерческая тайна заказчика:** реальные финансовые обороты, сканы договоров и прайсы поставщиков тканей без обезличивания.
4. **Правило ответственности (Раскрытие ИИ):** PM несет полную персональную ответственность за каждую цифру и ссылку в документе; использование ИИ для черновика явно фиксируется в метаданных отчета.
