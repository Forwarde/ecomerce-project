# Описание проекта: AtelierFlow

## 1. Концепция и проблематика
«AtelierFlow» — специализированная система для швейного ателье Айбола[cite: 5]. 
До внедрения учет велся на бумаге, что вызывало потерю мерок клиентов и закупку ткани «вслепую»[cite: 5]. Система переводит управление заказами и остатками материалов в цифровой формат[cite: 5].

## 2. Основной функционал
* База клиентов с фиксацией истории индивидуальных мерок[cite: 5].
* Складской учет рулонов тканей: метраж, цвета, составы и списание при раскрое[cite: 5].
* Трекер статусов пошива заказов[cite: 5].

## 3. Архитектура и стек
* Бэкенд: Python / FastAPI[cite: 5].
* База данных: PostgreSQL[cite: 5].
* Развертывание: Docker Compose[cite: 5].
* Архитектурные решения зафиксированы в подразделе: `docs/adr/`[cite: 7].
